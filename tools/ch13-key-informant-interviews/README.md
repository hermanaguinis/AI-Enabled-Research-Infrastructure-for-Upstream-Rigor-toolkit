# Key Informant Interview Research Tool

**Topic:** Qualitative and Mixed-Methods Research
**Original source page:** https://www.hermanaguinis.com/keyinformantinterviews.html
**Primary cited source:** Aguinis (2025), Research Methodology

## Description

Covers method-fit diagnosis, an assumption-challenging informant planner, a scored informant-priority table, access-route selection with generated outreach emails, an interview-format selector and dynamic protocol builder, power-dynamics and candor/confidentiality checklists, a triangulation matrix, disconfirming-case planning, and reviewer-facing and reflexivity checklists.

## Files

- `index.html` -- the tool itself. Self-contained HTML/JS, no external calls, no build step. Open directly in a browser.

## Data handling

Runs entirely client-side. See `/docs/data-handling-statement.md` at the repository root for the persistence model (localStorage vs. session-only) that applies to this tool.
