# Thought Experiment Designer

**Topic:** Vignettes, Online Samples, and Thought Experiments
**Original source page:** https://www.hermanaguinis.com/thoughtexperiments.html
**Primary cited source:** Weick (1989), Academy of Management Review 14(4):516-531

## Description

An eight-module tool implementing a 2x2 taxonomy of thought experiments (early/late stage by confirmation/disconfirmation, with Newton, Schrodinger, Galileo, and Einstein as exemplars), a decision tree for whether a thought experiment is appropriate, planning and execution guidance grounded in "disciplined imagination" (Weick, 1989), and a full worked example (workplace allyship, Type III) with export to Markdown/text.

## Files

- `index.html` -- the tool itself. Self-contained HTML/JS, no external calls, no build step. Open directly in a browser.

## Data handling

Runs entirely client-side. See `/docs/data-handling-statement.md` at the repository root for the persistence model (localStorage vs. session-only) that applies to this tool.
