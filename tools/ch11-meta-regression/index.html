About / source credit

This single-file offline tool operationalizes best-practice recommendations for metaregression as a method for assessing boundary conditions in meta-analytic evidence. It is designed as a decision aid and reporting scaffold, not as a replacement for statistical judgment or specialized meta-analysis software when complex dependencies, multilevel structures, or nonstandard effect-size metrics are present.

Methods and formulas
y_i = B0 + B1x_i1 + ... + Bjx_ij + u_i + e_i FE weights: w_i = 1 / v_i ME weights: w_i = 1 / (v_i + tau²_res) Q = Σ w_i (y_i - ybar_w)² I² = max(0, (Q - df) / Q) R²Meta = 1 - tau²_res / tau²_total

REML is implemented by optimizing the restricted log-likelihood over a nonnegative tau² range using a derivative-free one-dimensional search. Knapp-Hartung inference is implemented with t critical values and residual-scale adjustment. Power calculations are approximate and should be treated as planning/interpretive aids.
