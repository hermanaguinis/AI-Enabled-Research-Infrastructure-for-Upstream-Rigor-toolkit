# Experience Sampling Methodology (ESM) Study Designer

**Topic:** Market Basket Analysis, Experience Sampling, and Bayesian Analysis
**Original source page:** https://www.hermanaguinis.com/ESM.html
**Primary cited source:** Aguinis (2025), Research Methodology

## Description

Fourteen modules (A through N) covering ESM fit diagnosis, a research-question-to-design mapper, a protocol selector (interval/event/signal-contingent), a sample-size and data-point planner, a survey/codebook builder, a schedule generator, technology planning, recruitment scripts, a compliance-monitoring dashboard, a stacked multilevel data-structure builder, an analysis-plan generator, a validity/risk audit, an ethics/IRB module, and a reporting-package generator.

## Files

- `index.html` -- the tool itself. Self-contained HTML/JS, no external calls, no build step. Open directly in a browser.

## Data handling

Runs entirely client-side. See `/docs/data-handling-statement.md` at the repository root for the persistence model (localStorage vs. session-only) that applies to this tool.
