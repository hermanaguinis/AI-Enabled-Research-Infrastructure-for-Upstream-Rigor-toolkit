ProtocolBest use casesAdvantagesLimitationsData and burden implications
Interval-contingentFixed times or predetermined intervals; daily recurring states.Predictable, easy to explain, simpler schedule administration.Fixed-time bias; expectancy effects; may miss irregular events.Regular time grid; moderate burden if prompts are few.
Event-contingentSpecified events, rare events, social interactions, investor meetings, setback episodes, opportunity discovery.Captures focal events close to occurrence; efficient for infrequent phenomena.Requires clear event definitions; risk of underreporting; variable data density.Irregular rows; burden tied to event frequency; inclusion/exclusion rules matter.
Signal-contingentRandom prompts within time windows; broad sampling of states and contexts.Reduces fixed-time bias and expectancy effects; supports random sampling of real-world states.More intrusive; requires careful spacing and compliance tracking.Random time grid; burden depends on prompts/day and response window.

About this ESM Study Designer

This offline tool helps researchers design, conduct, monitor, analyze, and report experience sampling methodology studies. It emphasizes dynamic person-by-situation interactions, ecological validity, within-person and between-person logic, reduced retrospective bias, careful protocol choice, sample and burden planning, compliance monitoring, stacked data, and multilevel analysis.

Local-only operation: the file contains all CSS and JavaScript inline. It does not use external libraries, CDNs, APIs, fonts, or internet calls. Exported JSON, CSV, text, and HTML summaries are generated in your browser.
