Response-Rate Validity Assessment Tool

A self-contained offline tool for designing, documenting, and reporting evidence that a survey response rate supports defensible inferences about sample quality, appropriateness, and representativeness.

Module 1. Study setup

Enter enough information to calculate the response rate transparently and to evaluate whether the resulting sample supports the intended inferences.

Why this matters

Response-rate validity depends on more than a percentage. Transparent denominators, exclusions, eligibility decisions, recruitment mode, and data-quality procedures help readers judge whether the response rate is functional or dysfunctional for the study’s goals.

Module 2. Response-rate context and benchmark interpretation

Use benchmarks cautiously. A benchmark can contextualize the numerical response rate, but it cannot substitute for evidence about sample appropriateness and representativeness.

Enter benchmark information to generate a benchmark-caution statement.

Module 3. Validity-evidence assessment dashboard

Rate each validity-evidence domain from 0 to 4. Use the score as an organizing aid only; the final judgment depends on convergence across evidence, contradictions, red flags, and documentation gaps.

Rating scale guidance

0 = no evidence or serious threat. 1 = weak evidence. 2 = mixed or incomplete evidence. 3 = good evidence. 4 = strong evidence. A high score requires concrete documentation, not just an assertion.

Module 4. Functional vs. dysfunctional response-rate classifier

The classifier combines the numerical response rate, validity-evidence score, severe red flags, and documentation gaps. It never classifies the study based on the response-rate percentage alone.

Module 6. Nonresponse and representativeness checks

Plan analyses that make the response-rate validity claim more credible. Select each check you can conduct, then specify the comparison, available variables, strengthening/weakening evidence, and reporting plan.

Module 7. Survey-design improvement planner

Targeted recommendations are generated from missing denominators, low domain scores, red flags, and benchmark-comparability issues.

Module 8. Manuscript-ready reporting generator

Copy and paste cautious, transparent language into a Method section, reviewer response, limitations section, or online appendix. The language avoids claiming that the response rate proves validity.

Module 9. Reviewer audit mode

Paste a manuscript’s response-rate description, then complete the structured checklist. Because this file runs offline without AI APIs, the audit is implemented through guided self-assessment rather than automated natural-language analysis.

Module 10. Exportable outputs

Export a report, manuscript text, reviewer checklist, JSON backup, or CSV of scores and red flags. All exports are generated locally in your browser.

About / Citation

This tool operationalizes a response-rate validity assessment framework for evaluating whether a survey sample is high quality, appropriate, and representative for the intended inferences.

The tool is designed to help researchers gather and report validity evidence regarding the inferences supported by a particular response rate. The purpose is not simply to maximize response rate, but to maximize the quality and appropriateness of the sample for the study’s goals.

Based on: Aguinis, H. 2025. Research methodology: Best practices for rigorous, credible, and impactful research. SAGE. https://collegepublishing.sagepub.com/products/research-methodology-1-280088

Interpretation rule

High or low RR is not decisive. Functional RR requires convergent validity evidence. Severe coercion, unknown key qualifications, or serious data-quality failures override otherwise strong scores.
