# TheoryForge: Interactive Theory Elaboration Navigator

**Topic:** Theory Development
**Original source page:** https://www.hermanaguinis.com/Theoryelaboration.html
**Primary cited source:** Bacharach (1989), Academy of Management Review 14(4):496-515

## Description

Defines theory elaboration against theory generation and theory testing, a three-question decision tree (with published exemplars at each branch), all seven elaboration tactics across three approaches (contrasting, construct specification, structuring) mapped to Bacharach's (1989) five theory-quality criteria, six research-opportunity types, a full study planner that generates manuscript-ready text, and pre-readiness and pre-submission checklists.

## Files

- `index.html` -- the tool itself. Self-contained HTML/JS, no external calls, no build step. Open directly in a browser.

## Data handling
