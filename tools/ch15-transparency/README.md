# Methodological Transparency Companion

**Topic:** Research Transparency
**Original source page:** https://www.hermanaguinis.com/transparency.html
**Primary cited source:** Aguinis, Ramani & Alabduljader (2018), Acad. Management Ann. 12(1):83-110

## Description

Operationalizes all 44 disclosure recommendations from the source article as a trackable, filterable checklist (mark addressed / not applicable) that exports a manuscript-ready transparency appendix in Markdown and JSON.

## Files

- `index.html` -- the tool itself. Self-contained HTML/JS, no external calls, no build step. Open directly in a browser.

## Data handling

Runs entirely client-side. See `/docs/data-handling-statement.md` at the repository root for the persistence model (localStorage vs. session-only) that applies to this tool.
