# EVM Study Designer

**Topic:** Vignettes, Online Samples, and Thought Experiments
**Original source page:** https://www.hermanaguinis.com/vignettes.html
**Primary cited source:** Aguinis (2025), Research Methodology

## Description

Walks through all ten decision points and three stages (Planning, Implementation, Reporting) of Experimental Vignette Methodology design: EVM suitability, paper-people vs. policy-capturing/conjoint type, between/within/mixed design, immersion level, factors and levels with a live full-factorial calculator, vignette count, sample, setting and timing, analysis method (auto-recommending multilevel modeling for within/mixed designs), and a transparency checklist.

## Files

- `index.html` -- the tool itself. Self-contained HTML/JS, no external calls, no build step. Open directly in a browser.

## Data handling

Runs entirely client-side. See `/docs/data-handling-statement.md` at the repository root for the persistence model (localStorage vs. session-only) that applies to this tool.
