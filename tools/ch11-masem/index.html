Project setup

What this tool is designed to do

MASEM combines meta-analysis and structural equation modeling. The practical value is that researchers can use accumulated findings to evaluate competing theoretical structures, direct-effect models, mediated models, alternative variable orderings, and model fit rather than relying only on bivariate effect-size summaries.

This tool does not estimate final SEM models. It prepares, audits, documents, and reports the decisions required before running SEM in R, Mplus, Amos, EQS, or similar software.

Module 10. Positive-definiteness check — Decision Point 4

This is a browser-based screening check using the current matrix. It is not a substitute for SEM software diagnostics.
Common reasons and remedies
  • Sparse cells, small k or N, very high correlations, excessive imputation, surrogate variables, or broad poorly aligned constructs can produce nonpositive definite matrices.
  • Remedies include expanding the article pool, revisiting missing-cell decisions, reducing variables, defensibly combining overlapping variables, reconsidering imputation, and trying different starting values in SEM software.

About and credit

This interactive tool operationalizes guidance on using meta-analytic structural equation modeling to advance management and strategy research. It is designed as a practical, offline study builder for researchers, reviewers, and editors.

Credited source:
Aguinis, H. 2025. Research methodology: Best practices for rigorous, credible, and impactful research. SAGE. https://collegepublishing.sagepub.com/products/research-methodology-1-280088

Core caution: MASEM can compare theoretically meaningful alternative models and mediation chains using accumulated correlational evidence, but it cannot fix weak construct validity, sparse primary-study correlations, excessive missing-cell substitution, sample dependency, or causal identification limits in nonexperimental primary studies.
